# Explore SL — Tourism Website

A responsive multi-page tourism website concept for discovering destinations in Sierra Leone.

## Pages
- `index.html` — Home page and destination search panel
- `destinations.html` — Destination cards and working category filters
- `about.html` — About, story, mission, vision and values
- `gallery.html` — Image gallery with working category filters
- `blog.html` — Travel inspiration, article cards and newsletter demo

## Run the website
1. Extract the ZIP folder.
2. Open Visual Studio Code.
3. Choose **File → Open Folder** and select `Explore_SL_Website`.
4. Open `index.html`.
5. For the easiest local preview, install the **Live Server** extension in VS Code, right-click `index.html`, and choose **Open with Live Server**. You can also open `index.html` directly in a browser.

## Booking enquiry behaviour
The **Book Now**, **Plan Your Trip** and enquiry links open a form. It asks for a name, email, phone, destination, preferred date, number of guests and message. The form validates required fields and displays a confirmation reference in the browser.

**Important:** This is a front-end demonstration only. It does not send an email, connect to a database, store personal information, make a reservation or process payment. A real booking enquiry system needs a secure backend or form service and a privacy notice.
